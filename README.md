# IT Help Desk & Ticketing Management System

A web-based help desk system that allows employees to submit technical support tickets and lets IT support agents manage, assign, track, and resolve them from one centralized dashboard.

The system supports user roles such as Employee, IT Support Agent, Manager, and Admin. Employees can create and follow up on tickets, while support agents can update ticket statuses, add comments, and handle assigned issues. Admins can manage users, categories, priorities, and system settings.

The goal of this project is to improve how technical support requests are organized, tracked, and resolved inside a company.

## Main Features

- User login and role-based access
- Create and track support tickets
- Assign tickets to IT support agents
- Update ticket status and priority
- Add comments and attachments
- Send notifications for ticket updates
- Dashboard for ticket statistics and reports
- Database schema and ERD design
